# Mock-ups

- `png/00-overview.png`: all nine screens on one board, with captions.
- `png/01…09-*.png`: each screen at 1080 × 2340 (360 × 780 dp @3x), Android compact width, edge-to-edge, gesture navigation.
- `screens.html`: the static source. Open it in a desktop browser (file access to `../assets` and `../reference`). Add `?only=s3` to show one screen.

Map imagery inside the mock-ups is cropped from real screenshots of the web build. In the app it's the live MapLibre map with the effect layers from `docs/05-map-and-layers.md`. Numbers shown are real values captured on 15 Nov 2026 around 13:45 IST.
