HOW IT WORKS

FROM ORBIT TO STREET

  1. 01

    Retrieve

    Pull each variable from NASA APIs for Bengaluru’s bounding box.

  2. 02

    Process

    Parse, clean missing values and keep every unit explicit.

  3. 03

    Visualise

    Grid the values onto a MapLibre base map with deck.gl layers.

  4. 04

    Simulate

    Run what-if scenarios for heat, runoff and air flow.

  5. 05

    Validate

    Check coordinates, units and API responses against the source.
